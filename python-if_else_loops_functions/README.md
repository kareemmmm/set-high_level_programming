# Python - If/Else, Loops, Functions

This project covers conditional statements (`if`, `elif`, `else`), loops (`while`, `for`), and basic functions in Python, along with an introduction to working with C-linked lists and Python bytecode analysis.

## Repository Structure
* **GitHub Repository:** `set-high_level_programming`
* **Directory:** `python-if_else_loops_functions`

## Task Directory & File Breakdown

| Task | File Name | Description |
| :--- | :--- | :--- |
| **0. Positive anything is better than negative nothing** | `0-positive_or_negative.py` | Assigns a random signed number and prints whether it is positive, zero, or negative. |
| **1. The Last Digit** | `1-last_digit.py` | Prints the last digit of a randomly assigned number and applies conditional evaluation. |
| **2. Alphabet Game** | `2-print_alphabet.py` | Prints the ASCII alphabet in lowercase, using exactly one loop and one formatted `print`. |
| **3. Alphabet Soup** | `3-print_alphabt.py` | Prints the ASCII alphabet in lowercase except for the letters `q` and `e`. |
| **4. Hexadecimal Printing** | `4-print_hexa.py` | Prints all numbers from 0 to 98 in both decimal and hexadecimal format. |
| **5. 00...99** | `5-print_comb2.py` | Prints numbers from 00 to 99 in ascending order, separated by commas. |
| **6. Combinations of Two Digits** | `6-print_comb3.py` | Prints all possible unique combinations of two digits in ascending order. |
| **7. islower** | `7-islower.py` | A function that checks for lowercase characters without importing modules. |
| **8. To Uppercase** | `8-uppercase.py` | A function that prints a string in uppercase followed by a new line. |
| **9. Print Last Digit** | `9-print_last_digit.py` | A function that prints and returns the last digit of a passed number. |
| **10. a + b** | `10-add.py` | A function that adds two integers and returns the result. |
| **11. a ^ b** | `11-pow.py` | A function that computes `a` to the power of `b` and returns the value. |
| **12. Fizz Buzz** | `12-fizzbuzz.py` | A function that prints numbers from 1 to 100 with Fizz, Buzz, and FizzBuzz replacements. |
| **13. Insert in Sorted Linked List** | `13-insert_number.c`, `lists.h` | A function in C that inserts a number into a sorted singly linked list. |
| **14. Smile in the Mirror** | `100-print_tebahpla.py` | Prints the ASCII alphabet in reverse order, alternating lowercase and uppercase. |
| **15. Remove at position** | `101-remove_char_at.py` | Creates a copy of a string, removing the character at a specific index sequence position. |
| **16. ByteCode -> Python #2** | `102-magic_calculation.py` | A Python function matching a specified Python bytecode script behavior. |

## Requirements
* All Python scripts are interpreted and executed on Ubuntu 20.04 LTS using `python3` (version 3.8.5).
* All C files are compiled with `gcc 4.8.4` using the flags `-Wall -Werror -Wextra -pedantic -std=gnu89`.
* Code must strictly follow formatting and constraint criteria matching project requirements.
