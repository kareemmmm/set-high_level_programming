# High-Level Programming — Python Hello World

This repository contains foundational projects for learning high-level programming concepts using Python and C. It covers basic syntax, script execution, string manipulation, low-level data structure logic, and introductory compilation behaviors.

## Project Structure

The files are organized inside the `python-hello_world` directory as specified in the project requirements:

```text
set-high_level_programming/
│
└── python-hello_world/
    ├── 0-run                   # Shell script running a Python script from $PYFILE
    ├── 1-run_inline            # Shell script executing Python inline code from $PYCODE
    ├── 2-print.py              # Python script using the print function
    ├── 3-print_number.py       # Formatted printing using f-strings (integers)
    ├── 4-print_float.py        # Formatted printing with exact float precision
    ├── 5-print_string.py       # String repetition and slicing operations
    ├── 6-concat.py             # Formatted string concatenation
    ├── 7-edges.py              # String slicing techniques (first, last, and middle)
    ├── 8-concat_edges.py       # Slicing and combining multi-segment strings
    ├── 9-easter_egg.py         # Standard Easter Egg implementation (The Zen of Python)
    ├── 10-check_cycle.c        # C function optimizing cycle detection in a linked list
    ├── lists.h                 # C header file containing data structures and prototypes
    ├── 100-write.py            # Error stream output (`sys.stderr`) and exit statuses
    ├── 101-compile             # Shell script for manual Python bytecode compilation
    └── 102-magic_calculation.py # Python translation matching direct bytecode sequences
