======================
How to Use 1-my_list.py
======================

Importing the module and class:
    >>> MyList = __import__('1-my_list').MyList

Testing standard integer list sorting:
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Testing with negative integers:
    >>> my_list2 = MyList([3, -1, 0, -10, 5])
    >>> my_list2.print_sorted()
    [-10, -1, 0, 3, 5]

Testing empty list:
    >>> my_list3 = MyList()
    >>> my_list3.print_sorted()
    []
